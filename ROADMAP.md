# Nougat Studio Roadmap

Nougat Studio is being built as a director-first production environment capable of carrying a motion-picture project from concept through final delivery. The long-term target includes both live-action and animated production inside the same project system.

## Core principle

A production should not have to be rebuilt every time the filmmaker moves between writing, planning, shooting, animation, editing, sound, VFX, or delivery. Scenes, characters, locations, assets, timing, notes, and media should remain connected throughout the project.

## Phase 1 — Production shell and project navigation

- Film-strip visual identity and project dashboard
- Projects and recent-project management
- Screenplay and scene management
- Character and location management
- Storyboards and shot lists
- Production planning
- Media, editing, sound, VFX/color, export, tools, and settings workspaces
- Project-wide asset browser

## Phase 2 — Live-action production workflow

- Camera and lens planning
- Shot coverage and blocking tools
- Drone and aerial-shot planning
- Production schedules and scene breakdowns
- Camera/media ingest
- Dailies and review
- Voice recording, rehearsal, ADR, and dialogue tests
- Production notes and continuity tracking

## Phase 3 — Post-production and media tools

- Non-linear editing timeline
- Multi-track video and audio editing
- Trimming, ripple editing, transitions, markers, and scene organization
- Audio editing, dialogue cleanup, ADR alignment, sound design, and mixing
- Titles, credits, captions, and subtitles
- VFX and compositing workspace
- Color correction and grading workflow
- Media conversion/transcoding
- Media splitting and reassembly
- Proxy creation and media relinking
- Mastering and delivery presets

## Phase 4 — Animation production

Animation is a first-class production path, not a separate side application. Animated scenes should use the same projects, scripts, characters, shots, sound, editorial timeline, and delivery pipeline as live-action scenes.

### 2D animation

- Drawing and paint workspace
- Vector and raster artwork support
- Layers and exposure sheets
- Frame-by-frame animation
- Onion-skinning
- Keyframes and tweening
- Motion paths and transform animation
- Character rigs and reusable symbol/puppet systems
- Background and layout tools
- Camera moves across 2D scenes

### 3D animation

- 3D scene workspace
- Object transforms and hierarchy
- Character and prop rigs
- Skeletal animation
- Keyframe and curve editing
- Camera animation
- Lighting
- Materials and textures
- Environment and set assembly
- Particle/effects hooks
- Render queue and shot rendering

### Character performance

- Character libraries shared with screenplay and production tools
- Pose libraries
- Facial controls
- Lip-sync driven from recorded or imported dialogue
- Voice-track timing and phoneme markers
- Performance takes and alternate animation passes
- Motion-capture import as a future extension

### Animation cinematography

- Virtual cameras and lenses
- Shot framing tied to storyboard and shot-list entries
- Depth of field controls
- Camera paths, cranes, dollies, pans, tilts, and handheld-style motion
- Lighting plans shared with scene metadata
- Render-safe guides and aspect-ratio overlays

### Compositing and finishing

- Layer-based compositing
- Masks and mattes
- Keying
- Tracking
- Rotoscoping
- Effects stacks
- Render passes
- Color and grading handoff
- Direct placement of rendered animation shots into the main edit timeline

## Phase 5 — Hybrid productions

Nougat Studio should support films that mix production methods within the same timeline:

- Live action with animated inserts
- 2D over live action
- 3D characters or environments combined with camera footage
- Previsualization that can later be replaced by final photography or final renders
- Virtual-production planning
- VFX plates linked directly to shots and scene records

## Phase 6 — Advanced production systems

- Collaboration and project roles
- Review/approval states
- Versioned shots and takes
- Render farms / remote render workers
- Advanced proxy workflows
- Project archive and restoration tools
- Interchange formats for external professional tools where useful
- Extensible plugin/module architecture

## Product target

The practical test for Nougat Studio is simple: aside from physically capturing live-action footage with external cameras, a filmmaker should be able to bring the material into Nougat Studio and continue creating, changing, animating, editing, mixing, finishing, and delivering the movie without depending on a pile of unrelated applications.

Animation expands that target further: a filmmaker should eventually be able to create an animated film entirely inside Nougat Studio, from script and storyboard through character performance, rendering, editing, sound, and final master.
