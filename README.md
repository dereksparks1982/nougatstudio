# Nougat Studio

**Nougat Studio is a standalone, director-first film production environment built for serious motion-picture development, production, post-production, and delivery.**

Rather than treating screenwriting, pre-production, camera planning, audio, editing, media processing, and final delivery as separate islands, Nougat Studio is designed to bring the filmmaking pipeline into one coherent workspace.

It is intended for directors, independent filmmakers, cinematographers, editors, sound teams, producers, and other production professionals who want a single project environment that stays useful from the first story idea through the final master.

## What Nougat Studio Is

Nougat Studio is being developed as a browser-based professional production workspace with a strong emphasis on the director's point of view. The project is not limited to screenplay writing. Its goal is to connect creative development, technical planning, shooting, post-production, and media management in one system.

A director should be able to move from a scene in the script to its characters, blocking, shot design, camera requirements, drone coverage, voice tests, production notes, editorial material, sound work, and final media assets without abandoning the project environment.

## Production Pipeline

Nougat Studio is being built around the full filmmaking workflow:

- Screenwriting and story development
- Scene, character, location, and continuity management
- Shot lists, camera planning, lenses, movement, and coverage
- Storyboarding and visual planning
- Voice recording, character voice tests, rehearsal, and ADR planning
- Audio and sound-design workflows
- Drone and aerial-shot planning
- Production scheduling and scene breakdowns
- Camera and media ingest
- Dailies and review workflows
- Non-linear editing and post-production planning
- Media conversion, transcoding, splitting, and reassembly
- Project-wide media and asset management
- Export, mastering, and delivery workflows

## Director-First Design

The central idea behind Nougat Studio is simple: **the project should follow the film, not the software category.**

Scripts, performances, shots, sound, camera media, editorial decisions, and delivery assets all belong to the same production. Nougat Studio is designed to preserve those relationships instead of forcing filmmakers to rebuild context every time they move between tools.

The interface uses a modular production-workspace approach so different departments and stages of production can remain connected to the same scenes, characters, locations, notes, and media.

## Current Development

Nougat Studio is in active prototype development. The present web application establishes the director-first workspace, screenplay tools, scene management, character development, shot planning, storyboarding, research, and production structure while the broader production and post-production toolset is being brought into the standalone application.

The project is designed as a web application and is deployed through GitHub Pages.

## Project Goals

Nougat Studio aims to become a practical filmmaking environment that can scale from a single filmmaker developing an independent project to a production team coordinating a much larger film.

The long-term goal is not to imitate one existing application. It is to build a unified production environment around the way a film actually moves from concept to completed picture.
